# RocksDB interop oracle (Wave B)

Authoritative real-RocksDB fixtures for byte-exact interop verification.

`tests/fixtures/rocksdb/basic/` is a real RocksDB v11.4.0 database (format_version 5,
kNoCompression, block_size=256 so the SST has multiple data blocks):
keys `key000`..`key099` -> `value-000`..`value-099`, with `key050` deleted, flushed to one SST.
Generated by `gen_fixture.cc`. These are real RocksDB bytes (SST footer magic 0x88e241b785f4cff7).

## Regenerate (needs a built librocksdb.a)
    git clone --depth 1 https://github.com/facebook/rocksdb.git src
    cd src && mkdir build && cd build
    cmake .. -DCMAKE_BUILD_TYPE=Release -DWITH_TESTS=OFF -DWITH_TOOLS=OFF -DWITH_GFLAGS=OFF \
      -DROCKSDB_BUILD_SHARED=OFF -DWITH_SNAPPY=OFF -DWITH_LZ4=OFF -DWITH_ZSTD=OFF \
      -DWITH_ZLIB=OFF -DWITH_BZ2=OFF -DPORTABLE=1 -DFAIL_ON_WARNINGS=OFF
    make -j4 rocksdb        # -j4 (not -jN): RocksDB compiles are memory-heavy; -j12 OOMs on 14GB/no-swap
    g++ -std=c++20 -I src/include gen_fixture.cc src/build/librocksdb.a -lpthread -ldl -o gen_fixture
    ./gen_fixture /tmp/rdb_fix && cp /tmp/rdb_fix/{CURRENT,MANIFEST-*,*.sst,*.log,IDENTITY,OPTIONS-*} tests/fixtures/rocksdb/basic/

The zrocks interop test reads the committed fixture bytes; RocksDB is NOT needed at test time.
